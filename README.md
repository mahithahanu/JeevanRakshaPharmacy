# Pharmacy Management System — SQL Project

## About the Project

This project focuses on learning and practising SQL using a Pharmacy Management System database. It covers common pharmacy operations such as managing customers, orders, medicines, suppliers, and stock quantities.

## Database Tables

- **Customers** — Stores customer details.
- **Orders** — Stores customer orders and payment information.
- **OrderItems** — Stores medicines and quantities included in orders.
- **Medicines** — Stores medicine details, prices, stock quantities, and expiry dates.
- **Suppliers** — Stores supplier information.

## SQL Concepts Covered

- SELECT and WHERE
- Filtering with comparison operators, LIKE, and OR
- Sorting with ORDER BY
- Aggregate functions: COUNT, SUM, and AVG
- GROUP BY and HAVING
- JOINS
- Date filtering
- Stock updates and transactions using COMMIT
